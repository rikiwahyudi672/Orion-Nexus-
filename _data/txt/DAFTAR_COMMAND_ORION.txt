  8. VOICE ORION
================================================================

Test voice:
  python -c "from voice_orion import tts_supertonic_bytes; r = tts_supertonic_bytes('Halo Rik'); print(len(r) if r else 0)"

Fungsi voice:
  tts_bicara(teks)              → Putar di speaker lokal
  tts_supertonic_bytes(teks)    → Return bytes WAV
  tts_bytes(teks)               → Return bytes MP3 (Edge TTS)

Suara default: id-ID-ArdiNeural (Edge) atau F1 (Supertonic)

================================================================
  10. TROUBLESHOOTING
================================================================

[Discord bot tidak jalan]
  - Cek token: echo $env:DISCORD_TOKEN (harus 72 karakter)
  - Cek .env: Get-Content .env | Select-String DISCORD_TOKEN
  - Cek MESSAGE CONTENT INTENT di Developer Portal

[Voice Discord error]
  - Cek FFmpeg: ffmpeg -version
  - Cek PyNaCl: python -c "import nacl"
  - Cek TTS: python -c "from voice_orion import tts_supertonic_bytes"

[Coding loop error]
  - Cek GROQ_API_KEY: echo $env:GROQ_API_KEY
  - Cek .env
  - Test: python model_router.py

[Scan folder error]
  - Cek path folder ada
  - Cek permission
