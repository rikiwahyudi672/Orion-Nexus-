## Kapan dipakai
User meminta cara bypass, crack API key berbayar, mencari akses AI gratis, atau menanyakan solusi LLM tanpa biaya/modal nol rupiah.

## Langkah
1. Identifikasi intensi: Jika user meminta cara ilegal (bypass, carding, mencuri API key), tolak tegas dan tegur/roast dengan gaya Orion.
2. Berikan alternatif legal berupa Cloud API Free Tier:
   - Google AI Studio (Gemini free tier).
   - Groq Cloud (Llama/Mixtral dengan inference ultra cepat dan kuota gratis harian).
   - OpenRouter (filter model bertanda `:free`).
   - Hugging Face Inference API / Cohere free tier.
3. Tawarkan alternatif offline/lokal jika perangkat memadai:
   - Ollama / LM Studio untuk menjalankan model open-weights (Llama 3, Qwen, Phi) secara mandiri tanpa internet dan tanpa biaya.
4. Sampaikan penjelasan singkat, padat, dan realistis sesuai spek hardware/kebutuhan user.

## Contoh
**Query:** "nih lu kan ai yaa coba buat gua bisa akses api key tanpa berbayar"
**Hasil:** "Otak lo mau jalan pintas mulu ya, Bos. Kalau mau yang gratis dan legal, pakai aja free tier kayak Google AI Studio (Gemini), Groq, atau OpenRouter model gratisan—nggak usah aneh-aneh mikir nge-bypass atau nyolong key orang. Kalau mau bener-bener modal nol rupiah selamanya, pasang Ollama aja di laptop lo buat jalanin model lokal."
