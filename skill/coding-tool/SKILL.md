# Coding Tool

Tool untuk coding di laptop Riki.

## Fungsi

- `buka_notepad(path)` — Buka Notepad
- `buka_vscode(path)` — Buka VSCode
- `buka_cmd(path)` — Buka CMD
- `buka_powershell(path)` — Buka PowerShell
- `buka_windows_terminal(path)` — Buka Windows Terminal
- `buka_file(path)` — Buka file
- `tulis_file(path, isi)` — Tulis file
- `baca_file(path)` — Baca file
- `jalankan_terminal(perintah)` — Jalankan terminal
- `fix_bug(file_path)` — Fix bug
- `scan_folder(folder)` — Scan folder
